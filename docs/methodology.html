Lock down the
allowed paths.

The workflow begins with a deny-by-default policy and then opens only the minimum rules required for normal operation.

01

Define baseline policy

Set the default inbound policy to block and leave outbound access open for normal service traffic.

02

Allow only required services

Add rules for essential protocols only, including DNS, HTTP, HTTPS, and SSH where required for administration.

03

Test connectivity

Confirm that allowed traffic succeeds and that unexpected or unapproved ports fail as intended.

04

Capture evidence

Record status output, rule lists, and test results for the final report and portfolio submission.
